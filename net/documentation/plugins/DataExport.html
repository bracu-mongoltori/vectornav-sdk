Data Export¶

The Data Export plugin allows the user to export data from a VectorNav unit into various file types, such as a CSV, TXT, RINEX, IMR, or BIN file. Data can be exported from previously recorded log files as well as directly from a VectorNav unit in real time. Additionally, this plugin supports exporting to multiple file formats at once, including exporting any skipped byte data to a separate BIN file.

Each of the following exporter types can be obtained from the DataExport::Exporter class.

  • DataExport::ExporterAscii - exports to a TXT file

  • DataExport::ExporterCsv - exports to a CSV file

  • DataExport::ExporterSkippedByte - exports to a BIN file

  • DataExport::ExporterRinex - exports to a RINEX file

  • DataExport::ExporterImr - exports to a IMR file

This Data Export plugin can be used in conjunction with the Logger plugin, which allows users to log all bytes received from the VectorNav unit to a binary file without the parsing of any packets. Any files logged from the Logger plugin can then be exported into the desired file formats using this Data Export plugin. Information on how to log data from a VectorNav unit into a binary file can be found on the Logger page.

Usage¶

There are two examples for the Data Export plugin. One shows how to export data from a previously logged file and the other shows how to log data directly from the sensor.

Exporting from a File¶

When exporting data from a previously recorded log file, a Sensor object must first be created to process the logged data. Because the DataExport::Exporter class works with raw packets, it does not require the use of the CompositeData class for parsing. Therefore, the Sensor object should be configured with Sensor::MeasQueueMode::Off.

MeasQueueMode pushToCompositeData = MeasQueueMode.Off;  // do not parse to CompositeData because that is not needed by exporters
ByteBuffer mainBuffer = new ByteBuffer(65536);
ByteBuffer fbBuffer = new ByteBuffer(2048);

Sensor sensor = new Sensor(mainBuffer, fbBuffer, pushToCompositeData);

The desired DataExport::Exporter object should then be created. The DataExport::ExporterAscii class can only export logged ASCII output messages from the VectorNav unit, while the DataExport::ExporterCsv class can export both ASCII and binary output messages. The DataExport::ExporterSkippedByte class exports bytes that do not belong to any valid packet format, which is useful for debugging communication issues and data corruption. Once the DataExport::Exporter object is created, the Sensor object must subscribe to the exporter’s message queue.

DataExport.ExporterAscii asciiExporter = new DataExport.ExporterAscii(outputDirectory, DataExport.PacketQueueMode.Retry);
sensor.SubscribeToMessage(asciiExporter.GetManagedQueuePointer(), "VN");

asciiExporter = VNSDK.("DataExport+ExporterAscii")(outputDirectory, VNSDK.("DataExport+PacketQueueMode").Retry);
sensor.SubscribeToMessage(asciiExporter.GetManagedQueuePointer(),"VN");

DataExport.ExporterCsv csvExporter = new DataExport.ExporterCsv(outputDirectory, DataExport.PacketQueueMode.Retry);
sensor.SubscribeToMessage(csvExporter.GetManagedQueuePointer(), "VN");
sensor.SubscribeToMessage(csvExporter.GetManagedQueuePointer(), SyncByte.FA);

csvExporter = VNSDK.("DataExport+ExporterCsv")(outputDirectory, VNSDK.("DataExport+PacketQueueMode").Retry);
sensor.SubscribeToMessage(csvExporter.GetManagedQueuePointer(), "VN");

sensor.SubscribeToMessage(csvExporter.GetManagedQueuePointer(), SyncByte.FA);

DataExport.ExporterSkippedByte skippedByteExporter = new DataExport.ExporterSkippedByte(outputDirectory);
sensor.SubscribeToMessage(skippedByteExporter.GetManagedQueuePointer(), SyncByte.None);

skippedByteExporter = VNSDK.("DataExport+ExporterSkippedByte")(outputDirectory);
sensor.SubscribeToMessage(skippedByteExporter.GetManagedQueuePointer(), SyncByte.None);

Before connecting Sensor object to the file, the DataExport::Exporter object must be started. This will kick off a separate thread for the DataExport::Exporter object.

asciiExporter.Start();

asciiExporter.Start();

csvExporter.Start();

csvExporter.Start();

skippedByteExporter.Start();

skippedByteExporter.Start();

Once the different DataExport::Exporter has been started, the Sensor object should be used to connect to the log file, which will begin the exporting process.

sensor.Connect(filePath);

sensor.Connect(filePath);

Because the file is processsed in a background thread, the AsyncError queue should be monitored to detect when the end of the file is reached. A FileReadFailed native error will be returned, which will throw a VnFileException, indicates that the end of the file has been reached and processing is complete. The Sensor object can then be disconnected from the log file.

asciiExporter.Stop();

asciiExporter.Stop();

csvExporter.Stop();

csvExporter.Stop();

skippedByteExporter.Stop();

skippedByteExporter.Stop();

Exporting in Real-Time¶

When using the Data Export plugin to export data in real time from a VectorNav unit, it is first necessary to create a Sensor object and connect to the VectorNav unit, such as by using the AutoConnect() method.

Sensor sensor = new Sensor();
try { sensor.AutoConnect(portName); }
catch (VnException latestError)
{
    Console.WriteLine($"{latestError.Message} encountered when connecting to {portName}.");
    return 1;
}
Console.WriteLine($"Connected to {portName} at {sensor.ConnectedBaudRate()}");

sensor = Sensor();

try
    sensor.AutoConnect(portName);
catch latestError
    error('Error encountered when connecting to %s.\n%s\n', portName, latestError.message);
end
fprintf('Connected to %s at %s\n', sensor.ConnectedPortName(), sensor.ConnectedBaudRate())

Once the VectorNav unit is connected, the DataExport::Exporter object should be created.

DataExport.ExporterCsv csvExporter = new DataExport.ExporterCsv(outputDirectory);

csvExporter = VNSDK.("DataExport+ExporterCsv")(outputDirectory);

In order for the DataExport::Exporter object to export the desired messages from the sensor, the Sensor object must subscribe to the exporter’s message queue. In the example below, the DataExport::ExporterCsv object is used to filter for binary packets with an “0xFA” sync byte.

sensor.SubscribeToMessage(csvExporter.GetManagedQueuePointer(), "VN", AsciiSubscriberFilterType.StartsWith);

sensor.SubscribeToMessage(csvExporter.GetManagedQueuePointer(), "VN", VNSDK.AsciiSubscriberFilterType.StartsWith);

The DataExport::ExporterCsv object can subscribe to multiple message types at once. For example, while subscribing to the binary packets with an “0xFA” sync byte, the DataExport::ExporterCsv object can also subscribe to ASCII messages that begin with “VN”.

sensor.SubscribeToMessage(csvExporter.GetManagedQueuePointer(), new BinaryOutputMeasurements(), FaSubscriberFilterType.AnyMatch);

sensor.SubscribeToMessage(csvExporter.GetManagedQueuePointer(), VNSDK.BinaryOutputMeasurements(), FaSubscriberFilterType.AnyMatch);

The DataExport::Exporter object has now been set up, but has not yet begun exporting data. To begin exporting the subscribed messages, the DataExport::Exporter object must be started. After all desired data has been exported from the VectorNav unit, the DataExport::Exporter object must be stopped. This ensures all buffered data is exported to the output file.

Tip

Ensure the VectorNav unit is configured to output the desired data before starting the exporter.

if (csvExporter.Start())
{
    Console.WriteLine("Error: Failed to start logging to CSV file.");
    return 1;
}
Console.WriteLine($"Logging to {outputDirectory}");

DateTime endTime = DateTime.Now.AddSeconds(5);
while (DateTime.Now < endTime)
{
    System.Threading.Thread.Sleep(1);

    // Handle asynchronous errors
    try { sensor.ThrowIfAsyncError(); }
    catch (VnException asyncError)
    {
        Console.WriteLine($"Received async error: {asyncError.Message}");
    }
}

csvExporter.Stop();

if csvExporter.Start()
    error('Error: Failed to start logging to CSV file.');
end
fprintf('Logging to %s\n', outputDirectory);

secondsToRun = 5;
tic;
while toc < secondsToRun
    pause(0.001);

    % Handle async errors
    try
        sensor.ThrowIfAsyncError();
    catch asyncError
        fprintf('Received async error: %s\n',  asyncError.message);
    end
end

csvExporter.Stop();
